## Attempts Made Today

### 1. Full-frame offline person detector branch
- Direction:
  - YOLO person detector (`weights/yolov8s.pt`)
  - offline tracklets
  - global A/B assignment
- This was a major improvement over the old online/pose-first attempts.
- Good outcome:
  - much better tracking quality overall
  - much better speed than the old 55-minute versions

### 2. Zone-based person detection
- Attempt:
  - detect separately in near/far player zones to help far-side player visibility
- Result:
  - fixed one bug for `Player B` near `6s`
  - but regressed `Player A`
  - boxes became too small / unstable in later versions
- Conclusion:
  - rejected

### 3. Partial-box / guardrail tweaks
- Attempt:
  - suppress tiny partial boxes
  - add role-level guardrails
- Result:
  - helped some cases
  - but did not solve the deeper occlusion problem cleanly
- Conclusion:
  - not enough by itself

### 4. Bridge-tracklet experiments
- Attempt:
  - add supplemental bridging tracklets for a role
  - try to preserve A/B through short missing gaps
- What happened:
  - this often caused regressions
  - in some versions, a bridge tracklet got assigned in a way that:
    - duplicated A/B onto the same box
    - or revived the old wrong-assignment behavior
    - or made the tracker jump to neighboring-table people again
- User feedback:
  - these versions were "very bad" / wrong direction
- Conclusion:
  - rejected

### 5. Display-hold timeline experiments
- Attempt:
  - keep a role alive in render by holding the last good observation for a short time
- Versions generated from this direction included:
  - `debug_report/Vinh_set1_persondet_offline_50s_to_90s_v5_occlusion_hold_anchor.mp4`
  - `debug_report/Vinh_set1_persondet_offline_50s_to_90s_v6_occlusion_hold_longer.mp4`
- Result:
  - it could keep `Player A` visible longer through the foreground occlusion
  - but it was fundamentally only freezing the last good box
  - once the player moved or the box drifted, confidence decayed and tracking still died
- More importantly:
  - later variants started going in the wrong direction and risked breaking the clean `missing` behavior
- Conclusion:
  - rejected

### 6. Local occlusion tracker in render pass
- Attempt:
  - add short-lived local `OpenCV TrackerMIL` during occlusion
  - only in render pass
  - only after a recent confident observation
- Version generated:
  - `debug_report/Vinh_set1_persondet_offline_50s_to_90s_v7_local_occlusion_tracker.mp4`
- Internal result:
  - local tracker did follow `Player A` motion better than the frozen-box hold
- User feedback:
  - still not good enough
  - still considered wrong direction
- Conclusion:
  - rejected
